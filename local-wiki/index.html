pso-blender local wiki

PSOBB file formats

Local, static, no build step - open any page directly in a browser. One file per topic, plain HTML, add to it whenever something new gets confirmed. Companion to pso-blender-external-notes/next_subjects_to_work.md (the day-to-day backlog) - this wiki is the durable write-up, the backlog is where a session's raw findings get logged first. Each page carries a "last updated" date in its footer - bump it only when that page's content actually changes, not just because it was reopened.
